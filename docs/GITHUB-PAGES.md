# META TRACKER — публикация нового репозитория

1. Создать публичный репозиторий Meta-Tracker в аккаунте slrxm.
2. Загрузить содержимое проекта в ветку main.
3. В Settings → Pages выбрать Source: GitHub Actions.
4. Запустить workflow Deploy web app, если он не запустился после загрузки.
5. Дождаться успешного deploy и открыть адрес из результата workflow.

Ожидаемый адрес при таком имени репозитория:
https://slrxm.github.io/Meta-Tracker/

Сайт использует относительные пути и работает в подпапке репозитория.
Node.js сервер и SQLite на GitHub Pages не выполняются.
Текущий интерфейс использует сохранённый локально Dota ID и публичные API.

Для собственного обновления меты добавьте STRATZ_TOKEN в Actions secrets нового
репозитория. Секрет из frostmetax автоматически не переносится. Без него сайт
показывает включённый снимок данных, но Update meta не сможет получить новый.
metaUrl в app-config.json пока указывает на прежний публичный источник меты,
чтобы существующий источник оставался доступен мобильному приложению.

Настоящие ссылки Google Play и APK добавляются после выпуска Android.
Ключ подписи и APK в этот архив не включены.
